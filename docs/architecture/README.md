# Architecture records

Living how-it-works docs live under [`../read-write.md`](../read-write.md) (birds-eye pipeline), [`../orm/`](../orm/), and [`../query/`](../query/). This tree is for **why** and **not yet**.

| Folder | What belongs here |
|---|---|
| [`decisions/`](./decisions/) | Accepted ADRs: lasting choices, rationale, consequences |
| [`proposals/`](./proposals/) | Open designs — not done until accepted **and** built |
| [`proposals/archive/`](./proposals/archive/) | Closed proposals kept for history |

Do not treat ADRs or archived proposals as competing specs with the living docs. When they disagree, the living doc plus current code win; update or archive the record.
